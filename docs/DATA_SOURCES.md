# Data Sources

This project combines public web data from several sources.

## Leaguepedia / Fandom

Used for professional match history, patch information, teams, winners, picks, bans, and scoreboard-related data.

## OP.GG

Used as the external definition of patch-level OP champion-position tiers. OP champions were not selected after observing pro-match win rates.

## GOL.GG

Used as auxiliary champion-level statistics.

## Riot Data Dragon

Used for champion name/icon mapping during visualization. Downloaded champion icon image files are not included in this GitHub-ready package.

## Collection Caveat

Web crawling can break when page structure, API behavior, or access restrictions change. The included CSV outputs make the submitted analysis reproducible for review even if live crawling fails later.
