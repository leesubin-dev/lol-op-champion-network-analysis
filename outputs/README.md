# Outputs

This folder contains generated CSV outputs used in the report and presentation.

Important files:

- `data_quality_report.csv`: data collection and filtering summary
- `network_filtering_criteria.csv`: node/edge counts and filtering rules
- `op_status_winrate_summary.csv`: OP team win-rate, confidence interval, p-value
- `best_compositions_with_op.csv`: high-performing OP-included compositions
- `best_compositions_without_op.csv`: high-performing no-OP compositions
- `op_loss_opponent_combo_summary.csv`: opponent combinations that beat OP teams
- `champion_network_metrics.csv`: champion-level network metrics
- `model_performance.csv`: baseline/network model performance comparison
- `feature_importance.csv`: model feature importance
- `professor_quality_review.csv`: additional quality-review checklist
